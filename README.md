### 🏦 HDFC Bank — Cheque Truncation System (CTS)
> `Spring Boot` `Hibernate` `Oracle` `REST` `SOAP` `Spring Security`

Built and expanded secure backend modules for cheque validation workflows used in high-volume financial transactions. Optimized Oracle SQL queries to cut average query load times by **30%** and improved cheque processing speed by **20%**. Integrated multiple core banking systems via unified REST and SOAP APIs.
